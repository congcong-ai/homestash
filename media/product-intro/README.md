# HomeStash 产品介绍视频

本目录由 OpenFilm 0.2.6 制作，保留可编辑分镜、中文旁白、字幕和原创合成音乐。

## 交付版本

| 目录 | 用途 | 规格 |
| --- | --- | --- |
| social | 抖音、小红书竖屏 | 1080 × 1920，36 秒，30 fps |
| website | 官网、演示横屏 | 1920 × 1080，36 秒，30 fps |

两个版本分别排版，竖屏底部预留平台操作区域。字幕以各段旁白同名 WebVTT 保存，导出时烧录。

## 内容边界

画面为基于现有产品功能的动态交互示意，未使用真机实拍。FreshMate 外观为概念呈现，片内明确说明当前为开发板原型。语音记录、照片和小票辅助入库、临期提醒、菜谱与分步做饭等内容依据项目 README。没有宣传自动识别全部食材、声学唤醒已验收、消费级硬件已交付等能力。

库存保存在本地；使用第三方模型和语音服务时，相关输入会发往所配置的服务。“本地优先”不表示所有 AI 推理都在本地运行。

## 编辑与导出

在对应目录执行：

```sh
npx -y openfilm@0.2.6 open .
npx -y openfilm@0.2.6 look
npx -y openfilm@0.2.6 render --subtitles --out social.mp4
```

横屏版本将输出名改为 `website.mp4`。旁白来自 macOS 婷婷中文语音；音乐为本项目自行合成，不引用商业曲目。发布前可按品牌需求替换声音。
