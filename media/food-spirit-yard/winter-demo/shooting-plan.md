# 萌小冰立冬演示拍摄单

片名《立冬这天，小冰帮我留了一张照片》。建议实拍一遍 90–120 秒的完整流程，再分别补拍屏幕和道具。以下按竖屏 60 秒排。

| 成片 | 画面与动作 | 台词或字幕 |
| --- | --- | --- |
| 00–04 秒 | 饺子出锅一闪，切冰箱贴和手指靠近屏幕 | 「今天立冬，我想让小冰帮我留张照片。」 |
| 04–12 秒 | 电脑 Web「教小冰怎么接话」录触发词和保存，再补一闪主题设置 | 触发词「我回来啦」。预设台词「回来啦！今天立冬，想吃饺子还是喝热汤？」 |
| 12–28 秒 | 点设备「唤醒」，听到本地招呼后说触发词。给屏幕表情和播报特写。播完直接追问，手离开屏幕 | 「我回来啦。」→ 保留设备原声 →「那饺子蘸什么？一句话告诉我。」→ 留一句实际回答 |
| 28–42 秒 | 把饺子推入实拍取景，点设备「拍照」。切手机的真实新预览，输标题，点保存 | 手机网页标题「立冬第一盘饺子」。保留保存动作与回忆卡出现 |
| 42–48 秒 | 电脑录同标题、同照片的家庭回忆卡，切到「冰箱拾光」选今天、生成回忆册后的结果 | 「照片和今天的对话，都在这里。」按实际生成结果配字幕 |
| 48–60 秒 | 翻到单独准备的故事样张。画面先停大标题和同一张现场照片，再轻滑到故事结尾 | 小字「故事样张 · 人工整理」。收尾「今年立冬，就记住这盘热乎的饺子。」 |

## 现场按这个顺序

1. 电脑、设备、手机进同一局域网。确认设备在线、手机浏览器能打开「食灵小院」、相机能取到盘子，先录一条备用实拍链路。
2. 电脑预设规则，避开现有同名触发词冲突。换主题可用「暖暖小豆」，待设备空闲更新后，分别录网页选择和真机变化。先在真机走两句，确认实际文案和自动接话。
3. 一人操作、说话和端盘，一人拍设备和道具。电脑与手机各自录屏，保留一次完整点击和结果。同一盘饺子贯穿设备照片、手机预览、Web 回忆卡和故事页。拍照前结束对话，设备空闲再按主屏按钮。
4. 预览出现后用手机确认保存。电脑打开「互动记录」「家庭回忆」「冰箱拾光」核对素材，必要时补录。把同一张实拍照片选入同目录的 HTML 样张，按当天实际对话改两段正文，再录结尾。刷新会清空本地选图。
5. 额外补录 3–5 秒一条的功能素材。真机录全屏角色、触屏停止、Wi-Fi 已连接状态。电脑录设备状态、伙伴与互动记录、表情设置。手机录照片预览、重拍与保存，重拍放在备用那条录。剪辑有空间时用三联快切，主线优先保留完整对话和拍照回执。

## 剪辑与演示口径

- 等待模型回复、设备传图的空档可剪掉。设备原声留完整，手机录屏放大到「预览、保存、回看」三个动作，结尾故事页至少留 8 秒。
- 手机展示的是同一个局域网网页。立冬固定台词用后台规则确保能拍到；当天节气卡实测出现时可以补一个镜头。主线用已经验收的触屏唤醒和拍照。真实开门唤醒、声纹、语音拍照与离线续传留给各自的专项实测。
- 产品里的「冰箱拾光」现有工作区实现为按日期汇集对话和照片。图文故事由同一段实拍素材人工整理为独立 HTML，片中保留样张标识。选用演示照片和记录，开录前收起 Wi-Fi 密码、模型密钥及私人家庭记录。
