# Core断线后的只读离线查询

更新：2026-10-27。

## 开启和使用

在线登录后进入“设置 → 断线时也能查一查”，主动选择“在此浏览器保留离线副本”。默认关闭，不会因为访问页面就自动保存家庭库存。这里也可以立即同步、清除或单独打开只读查看器。

Core断线时应用进入独立只读页面，可搜索库存和位置、查看采购余量、食谱步骤及做饭进度快照。页面明确显示最后同步时间、副本到期时间和同步时的家庭日期；临期状态及食谱仅代表当时数据，不能当作最新库存事实。

离线没有添加、消耗、收货确认、语音上传、做饭推进或设备控制入口，API客户端也在发请求前阻止写入。不会排队补交操作。Core恢复后，已打开应用自动读取最新状态，关闭旧编辑上下文并提示重新核对。整个网页服务也断开时，恢复网络后点击“重连并核对最新数据”进入正常应用。

## HTTP与安全上下文的区别

- 普通HTTP局域网：不注册Service Worker。网页服务仍在线、只有Core断线时可以查看副本；整个网页服务停机后不能保证刷新或重新打开。
- HTTPS或浏览器认可的本机安全上下文：Service Worker只缓存静态离线查看器及其模块，不缓存Next应用、API或登录响应。安装完成后，即使整个服务不可达，重新打开网页也能显示有效副本。
- 首次访问尚未缓存、浏览器清理存储、空间不足或副本过期时，没有可用数据；界面会说明，不显示假成功。

本轮真实测试了本机安全上下文的Service Worker断网导航，不代表已完成实体手机HTTPS或安装式PWA验收。

## 缓存和登录边界

副本保存在当前浏览器当前来源的localStorage中，是可读的本机副本，不是加密保险箱或独立身份认证。公共设备上请勿开启。不同浏览器、来源和设备不自动共享。

只保存白名单字段：物品名称/类别/数量/单位/位置和同步时的日期提醒、清单余量、食谱步骤及当前做饭步骤。不会保存AI配置/API Key、设备令牌、登录口令、Cookie、库存原始metadata、事件内容或原图。

Core为已登录会话提供匿名分区及真实会话到期时间，未暴露Cookie或签名密钥；无登录的Local Mode使用最多12小时的本地期限。副本最多12小时，已有登录更早到期则随之失效。查看器拒绝过期、非法时区或损坏数据，并清除不可用副本。

登录页、退出登录和明确401都会清除副本及开启偏好；跨标签页清除会生效。离线退出先清除本机副本并记录待完成退出，重连后先清除远端Cookie，再允许重新登录；无登录Local Mode不会因此陷入无法重开的登录页。登录表单的无JavaScript回退使用POST，避免口令进入URL。

离线期间无法即时获取服务端账号配置变化、会话撤销或其他终端更新。重连后必须以Core响应为准；浏览器副本不替代正式备份，不支持离线库存修改与冲突合并。

## 验证

新增6组软件测试：默认关闭/过期和坏数据、白名单投影、登录租约与匿名分区、断线退出补办、写请求拦截、配额不足及不清除其他应用数据。全量94项软件测试、lint、typecheck和生产build通过。

Chrome手机模拟包含原74项基线、HTTP局域网11项、本机安全上下文12项及320像素布局/登录回退3项检查。覆盖Core断线只读、搜索/切换、其他终端修改后重连更新、整个服务不可达后重新导航、过期拒绝、离线退出及重新登录默认关闭。使用独立临时SQLite，真实手机和外部模型本轮未测，未修改日常库存、固件、SmartBadge或历史migration。
