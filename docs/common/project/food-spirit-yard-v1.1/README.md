## 可直接复制的新会话提示词

真实门触发、自然接话、食灵共创、用户确认后拍照留影、家庭回忆卡是主线；精准库存和原 P2 不做。保留现有后台与数据，只新增必要接通，不重写后台。优先 T5，保留已有固件分层和锁定 SDK，摄像头目前缺件，声纹须验证真实身份输出。

语音是本次重点：05 已确认当前代码为百炼云端 TTS＋本地格式转换＋整段下载，并未发现先普通音频再萌化的二次合成。请补真实分段测量，支持本地固定提示、现有云端与可配置本地主机 HTTP TTS，分别验证缓存、取消和首音优化；不要把切到云端当成现有已是云端方案的修复。

保护工作树中已有文档/固件迁移，不还原、不清空、不混入提交。不要只交方案或静态页面，也不要因硬件缺件停止其余可验证的软件实施；真实/模拟、构建/真机结果分别报告。全部回复和文档用中文。
