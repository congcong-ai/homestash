# 配网布局优化与XM路由器连接

日期：2026-11-06。用户反馈网络列表太小，要求优化网络选择、热点信息与密码输入，并授权将开发板连接电脑同用的XM路由器。

## 实现

- 配网拆成全屏网络选择页与独立密码页，避免列表、输入框、键盘挤在一页。
- 网络列表宽456、高176，行高至少56、间距8，可滚动；当前SSID固定在顶部，长名称滚动显示，列表标出已连接网络。
- 选中AP复制自当前显示列表快照，避免刷新扫描排序后点错网络。
- 独立密码页：56高输入框、显示/隐藏按钮、144高键盘、独立连接保存与返回。返回或成功提交清空输入；密码不写聊天/日志。
- 保留现有网络服务、设备凭据与KV持久化，不格式化SD或修改数据库。新增HTTP结果脱敏日志只记录路由与状态码，不记录头部Token或请求正文。
