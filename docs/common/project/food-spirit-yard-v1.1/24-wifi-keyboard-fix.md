## 已复现的原因与修复

锁定SDK的lv_keyboard构造器使用LV_ALIGN_BOTTOM_MID。原调用lv_obj_set_pos(keyboard,0,160)保留该对齐方式，将键盘向下偏移至y=328..471，完全超出480×320屏幕；并非仅凭缺少焦点事件推断根因。

改用lv_obj_align(keyboard,LV_ALIGN_TOP_LEFT,0,160)，密码页边框归零、保留8px内边距，实测键盘y=168..311。选SSID、点击/聚焦密码框、切换显示密码均重新绑定textarea、移除HIDDEN并置前。新SSID重置小写模式、清空密码；完成键收起键盘后点击输入框可恢复。键盘取消按返回处理，清空输入、恢复掩码并解绑；不删除已保存网络。
