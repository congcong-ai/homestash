# 默认开发启动与旧进程抢占修复

2026-11-06。用户实际执行pnpm dev后，可通过127.0.0.1:3001打开网页。现场核查其设备端口同样仅监听127.0.0.1，无法供T5访问。此前确实执行过dev:lan，但普通dev与旧watcher重启可覆盖现场监听状态。

## 实施

pnpm dev默认执行scripts/dev.mjs --lan，复用已有LAN模式和preparePort，网页输出可访问LAN地址；dev:lan保持，新增dev:local显式提供本机模式。沿用已有可信家庭LAN授权、内部Core回环监听、设备独立鉴权，不暴露密钥。

preparePort沿当前监听者的父链核对本项目真实路径，优先停止对应scripts/dev.mjs启动器或Core watcher，避免只终止子进程后立即抢回端口；不遍历杀死其他端口的会话。路径比较使用realpath兼容macOS临时目录/private别名，其他项目进程保持。

## 验证

CLI网络回归7/7通过，包括真实子进程自动拉起的旧启动器清理测试。初次新增回归暴露临时目录别名匹配失败，修复realpath后通过。ESLint与git diff --check通过。

实际执行pnpm dev，已正常就绪，设备接口*:3101，网页http://192.168.66.37:3000/app/yard。随后再次执行同一命令，验证旧启动器停止与重新启动。该结果只证明服务启动与监听，不将主机请求当作设备心跳；Core真实联通仍待验证。
