# Web 用户后台重构记录

日期：2026-11-05。范围仅 Web 后台，不涉及固件、硬件工具、串口、主会话数据库或其服务端口。

## 产品入口

依据最新授权，以萌小冰·食灵小院取代旧库存后台 UI。`/app` 和 `/app/backoffice` 均进入 `/app/yard`，主导航为小院概览、我的设备、互动记录、食灵角色、家庭回忆、语音与设置。保留现有数据库、旧业务 API、认证与设备密钥边界；没有数据迁移、清库或历史 migration 修改。本轮无需 Core 增量，直接复用已存在的真实接口。

## 实际改动

- 新增设备区，读取 `/api/devices`，展示设备名称、编号、板卡、网络上报、固件版本、最近心跳及声明能力。沿用服务端 45 秒心跳在线判定，每 15 秒自动读取并支持手动刷新。读取失败明确显示状态待刷新；空库显示未登记，不生成假设备。设备能力声明不当作外设验收结果。
- 小院共享状态每 15 秒读取 `/api/yard`；轮询不覆盖正在编辑的角色与语音表单。互动记录最多展示最近 20 条，按真实 simulated 字段标注网页模拟或设备互动，并显示时间。
- 继续使用角色 PATCH、许可、预览、重拍、取消、保存、私有照片和删除 API。设备照片与模拟预览采用不同标签，回忆默认标题使用不虚构角色名称的“今天的小院合影”。
- 保留独立 ASR/TTS、模型/音色选择、试听、恢复默认和服务端凭据边界；试听对象 URL 随替换或卸载释放。
- 移除旧后台主导航与跳转，更新后台页面标题。移动端横向导航、设备信息自动换行、双列能力摘要和回忆卡适配小屏。
