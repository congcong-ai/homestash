# 唤醒导航、角色图标与“退下”停止

2026-11-07 用户最新要求：底部只保留唤醒、拍照、回忆；停止移到角色旁，仅激活时显示；全屏与停止相邻，采用图标，样式区别于底部导航。说话时说“退下”应达到点击停止的效果。

## 实现

- 标准480×320底部三按钮，148×44、间隔10，接话改为唤醒。
- 角色右上方相邻两个44×44圆形图标：浅灰绿全屏四角图标、浅粉停止方块图标，间隔8。全屏时移至右上角，返回图标仍可退出，激活时停止仍可见。停止与底部导航独立，网络/设置面板不受影响。
- 主循环提交明确的激活状态：唤醒/收音/业务等待/播报/拍照显示停止，空闲/取消隐藏；后台维护任务不显示停止。停止信号入口即清除激活标记，取消中的旧worker不让按钮复活。
- 独立“退下”“退下吧”“小冰，退下”等指令返回语义action=stop；“退下是什么意思”“不要退下”等不触发。跳过自由聊天模型和TTS，设备将该动作送进同一停止事件，清空旧会话并退出自动接话。
- 现有AEC收音能量检测先暂停旧播报，再通过Core在线ASR辨认用户说的话；普通插话仍接话，“退下”则休息。不是板端离线关键词识别，不宣称说出两个字瞬时本地识别。
- 动态播报和本地招呼均支持打断。本地PCM发现有效插话后提前退出，静音排空，沿用前段语音缓冲继续收音；重置招呼去抖避免短时插话被冷却吞掉。关闭自动续轮也保留播报中语音停止的入口。
