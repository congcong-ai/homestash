# 萌小冰 · 食灵小院｜黑客松汇报底稿

2026 年 11 月 7 日 · 供制作 PPT 和现场演示使用

## 第 1 页｜封面

**主旨：把冰箱旁的一句话，变成全家能一起留下的回忆。**

- 萌小冰是一个会接话、会变表情的互动冰箱贴原型。
- 食灵小院是家人一起养角色、改台词、存回忆的地方。
- 台上用一块涂鸦 T5、一个 USB 摄像头和电脑上的小院网页完成演示。

素材建议：同框拍一张设备和小院网页的合照，屏幕使用测试场景。 [产品定位](01-product-requirements.md)

## 第 2 页｜为什么从冰箱旁开始

**主旨：买了什么、今晚吃什么、这道菜谁做的，都是可以顺手聊起来的话题。**

- 一句“今天买了草莓”，就能引出一个草莓食灵。
- 家人可以给食灵取名、教萌小冰一句新的接话。
- 想留念时拍张照片，先看一眼，再决定要不要存进小院。
- 这版围绕食物互动和家庭回忆设计，产品入口聚焦角色、对话与回忆。

讲述口径：这是团队选择的生活场景与产品假设。草莓食灵已有真实语音创建记录，现场口述改名属于待单独验收项。 [产品取舍](01-product-requirements.md) · [草莓食灵与改名记录](26-overall-acceptance-20261107.md)

## 第 3 页｜点一下唤醒，接着聊

**主旨：一次唤醒，可以接着聊两轮。**

- 点屏幕上的“唤醒”，萌小冰先用板上的短音频打招呼，六句轮换。
- 开口后，设备收音，电脑上的 Core 处理识别和对话，设备播出动态回复。
- 真机已确认连续两轮自动接话。想结束时，点角色旁的停止图标。
- 倾听、等待和播报各有对应的表情，嘴巴随实际播放开始和结束。

素材建议：录一段「点唤醒 → 提问 → 播报 → 直接追问」的真机短片。 [连续接话](23-discovery-short-replies-and-interruption.md) · [本地招呼](25-local-greeting-rotation.md) · [动画实测](28-avatar-animation-upgrade.md) · [触屏停止](30-avatar-controls-and-voice-stop.md)

## 第 4 页｜教它怎么接话，换一张它的脸

**主旨：家人可以在网页改台词、换表情主题，设备免刷更新。**

- 在网页设置一句触发词和台词。说“我回来啦”，真机已按更新后的规则播报。
- 四套内置主题：薄荷团子、桃桃方糖、暖暖小豆、晚安月团。轮廓、眼型和配色各有区别。
- 标准模式保留文字和操作，全屏模式把画面留给角色，点右上角可返回。
- 真机已确认免刷切换、全屏返回，以及断电重启后保留所测主题和布局。

素材建议：截取测试页面的规则编辑区和主题选择区，配一段真机全屏切回标准的短片。网页预览和真机画面各自标明。 [规则真机记录](21-story-rule-rehearsal.md) · [主题与布局验收](28-avatar-animation-upgrade.md)

## 第 5 页｜按下拍照，选一张留下来

**主旨：照片由设备现场拍，家人自己决定哪张进回忆。**

- 在 T5 主屏点“拍照”，接入的 USB 摄像头采集新照片。
- 网页上看预览，可以重拍、放弃，也可以写个标题后保存。
- 真机、网页和服务已串通，设备和 Core 重启后仍能回看此前保存的照片。
- 预览与正式回忆分开，适合现场做一次从拍摄到回看的完整演示。

素材建议：拍摄赛场道具或获授权的演示对象。制作 PPT 时可用流程图与去敏证据。 [拍照验收](23-photo-product-flow.md) · [结构化证据](evidence/rehearsal/photo-product-flow.json)

## 第 6 页｜设备、电脑和网页各做什么

**主旨：设备负责当场反馈，电脑处理对话和保存，网页负责编辑与回看。**

- **设备**：T5 负责触屏、表情、录音、播报和 USB 相机采集。固定招呼保存在板上。
- **电脑**：局域网 Core 负责规则、对话处理和回忆存储。动态对话使用配置的模型服务。
- **网页**：编辑台词和主题，管理照片预览与家庭回忆。
- **连接**：设备已实测在屏上输入密码连入新 Wi-Fi。在同一局域网、Core 可达时，设备已实测能从旧地址自动发现新的 Core 地址。

素材建议：画「T5 ↔ 局域网 Core ↔ 小院网页」三节点图，在 Core 旁标出模型服务。 [触屏配网](24-wifi-keyboard-fix.md) · [局域网发现](23-discovery-short-replies-and-interruption.md) · [设备连接证据](evidence/rehearsal/core-connection-acceptance.json)

## 第 7 页｜现场演示顺序

**主旨：用同一台设备走完“接一句话、留一张照片”。**

1. **开场前**：确认 T5 和电脑在同一网络、Core 在线，打开小院网页，核对当前规则触发词、USB 相机取景和音量。
2. **先聊**：点“唤醒” → 说“我回来啦” → 听实际规则回复 → 直接问“番茄炒蛋怎么做？”，用一轮简短追问带出连续接话。需要结束时点屏上的停止图标。
3. **再拍**：点主屏“拍照” → 网页出预览 → 选保存并回看。有余量再演重拍，或全屏切回标准。
4. **有余量再展示配置**：后台换已验过的主题，等设备空闲拉取后展示外观变化。若网络或收音影响现场效果，用预先录制的去敏真机片段，并标明为实录回放。

主线走触屏唤醒与拍照。将口述“退下”、说一句话触发拍照、开冰箱门自动唤醒留在进展页。 [整体验收](26-overall-acceptance-20261107.md) · [网页及协议补验](27-unattended-acceptance-20261107.md)
