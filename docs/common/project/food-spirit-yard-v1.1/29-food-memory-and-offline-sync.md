# 食物互动、成员与离线回忆增补

2026-11-07 用户新增范围，待实施，不代表已验收。

## 用户确认

- 不做精准库存、余量、保质期。围绕当下吃饭互动，记录吃什么、谁做的，提供做法帮助，形成家庭回忆。
- 激活先用本地默认招呼；对话期间后台检查饭点和当日是否问过，不能让查询阻塞首次反馈。
- 仅在时间可靠时使用中国饭点；按北京时间的日期和餐次持久化去重，不重复询问。
- 未知成员可自然询问称呼、建立档案；真实声纹录入与下次匹配须核实服务支持，未知匹配不能假装识人。
- 录音、照片先保存SD；无Core或无网络时保留；联网且空闲再自动续传，不能抢占接话、停止或拍照。
- 后台保存录音；用户可独立选择是否启用付费AI转写、说话人识别。保存与付费分析解耦，不因上传自动收费。

## 实施边界与依赖

默认饭点建议：早餐07:00–09:30、午餐11:00–13:30、晚餐17:00–20:00，均北京时间，后台可调。该时间窗为设计建议，非用户已指定的精确值。

需审计当前SDK可信时间来源、SD剩余容量、录音outbox完成删除行为、相机JPEG生命周期、后台音频保留路径和SpeechProvider声纹能力。现有录音失败重试队列不等于持久回忆队列；不能直接改变旧队列删除行为导致旧回复复播。

新增独立媒体待同步清单，状态至少包含待上传、上传中、服务确认、失败重试；文件先写临时名再原子提交，上传幂等，断电可恢复。服务确认前不删除本地原件。空间耗尽须可见且停止新增，不能覆盖旧回忆。后台AI处理配置独立于实时ASR对话配置，避免关闭回忆转写破坏正常接话。

餐次提示先持久化领取记录，再返回提示；同一次重试不能多问。已谈到本餐吃什么也应视为无需再问，未知时间或无有效状态时跳过主动问题。称呼自述与声纹匹配证据分别存储；可靠匹配前不自动归属。

验收需覆盖重启去重、跨北京时间日期、无可靠时间、后台关闭、断网/断电恢复、重复上传、空间不足、停止抢占、AI开关不触发付费请求，以及声纹真录入与至少两人区分。当前均未完成。

## 本轮已实现的软件

- 北京时间餐次计算、设置、当日餐次去重及原话吃饭小记；新页面可编辑三个饭点。时间来自Core系统时钟，拒绝不合理年份，未宣称板端NTP已验证。离线时不主动猜饭点。
- 独立SD recordings目录保存WAV/JPEG。照片临时文件完整写入、sync后rename；录音在实时播报完成后同卷原子移动，避免首音前复制PCM；总量64MB/1000文件的有界保护，满时拒绝新增并显示错误，不覆盖历史。原实时outbox与回忆队列隔离，避免补传触发旧回复。
- 未激活、非录音/非业务忙碌/无待处理语音时才调度上传；接话/停止/拍照入口先取消维护传输。HTTP等待以250ms小段检查取消，停止响应还包含平台发送/文件I/O的实际耗时，真机仍需测量。
- 录音原件经独立鉴权接口保存，服务端确认相同ID后SD标sent；本地原件保留。Core中的待分析状态持久化，重复上传不重复建条目，默认不调用AI转写。后台任务启用后只在设备报告空闲时运行；收到激活通知/实时录音请求即Abort，保留pending；网络错误一分钟后再尝试。远端模型服务是否停止计费不能由本地Abort保证。
- 本地唤醒招呼与异步active通知并行，不等待网络回执。设备空闲设置请求恢复后台任务许可；网络无法传达激活通知时，Core不能瞬间得知设备状态，不能声称跨断网的绝对实时抢占。
- 照片先采集写SD，再尝试原实时预览；未成功时保留独立待同步照片。后台补传进入“待整理照片”，选择保存后进家庭回忆，放弃后云端图片不可回看，重复补传不复活。离线拍摄时间未可靠取得，仅标上传时间。用户放弃/停止照片在SD的本地原件当前仍保留，不冒称已从SD删除。
- 百炼Key后台私有文件0600保存，接口不回显；统一聊天/ASR/TTS配置动态读取。未修改或输出既有.env密钥；没有自动开启新Key/付费分析。新配置尚未进行真实百炼付费请求验收。

## 声纹核实结论

用户指定统一阿里百炼。当前SpeechProvider原来只有ASR/TTS，本轮未接入真正的多成员声纹注册/1:N匹配，因此暂不启用recognizeSpeaker，也不自动把名字与声音绑定。用户自述称呼的成员建档问答仍未实现，不把普通文本名字当作声纹。

官方非实时识别的说话人分离是在录音内区分话者；Qwen-Audio实时接口的说话人增强是提供预录音频锁定目标话者，两者都不足以证明本项目已有跨会话家庭成员识别。需要进一步核实可返回成员ID的接口和账户授权，不能假装完成。
