# Local Mode当前阶段软件验收

更新：2026-10-27。对照根目录00/01/02文档及用户后续“大功能优先”的顺序，本页记录当前授权软件范围，不代表所有长期路线完成。

## 大功能验收矩阵

| 主流程 | 当前证据 | 结论 |
|---|---|---|
| 文字模拟语音→结构化意图→库存事件→SQLite | Domain/API回归与手机模拟 | 已实现，模型不直接操作数据库 |
| 库存批次→临期→事件纠正→家庭时区 | 库存、日期和备份测试；手机模拟 | 已实现 |
| 库存→食谱→烹饪续做→明确确认消耗→再次补货 | 日常流程回归及浏览器基线 | 已实现；Mock使用本地规则，真实模型准确性不由此证明 |
| 图片/条码/订单→候选核对→分批入库 | 专项回归、此前真实百炼虚构图与浏览器专项 | 已实现；实物及平台截图准确率需样本验收 |
| 采购计划→订单实收→库存→清单余量→另买后补齐 | 采购关联6组回归、7项手机专项 | 已实现，无自动名称猜测或单位换算 |
| 备份→校验预览→覆盖恢复→恢复前快照回退 | 备份及整链测试、此前临时库浏览器专项 | 已实现，不包含机器秘密配置 |
| Core断线→只读副本→过期/清除→重连更新 | 离线6组回归、26项浏览器专项 | 已实现；HTTPS/本机安全上下文与HTTP局域网的能力分开说明 |
| 登录→离线退出→清除副本→补办远端退出→重新登录 | 会话回归及离线浏览器专项 | 已实现，副本默认关闭；本机副本不是独立离线认证系统 |

本轮软件共94项、既有手机模拟基线74项及离线专项26项通过，lint、typecheck和生产构建通过。测试数据库与日常库存隔离，浏览器检查使用Chrome触屏仿真。全局回归同时覆盖订单/采购关联与已有设备协议；不是再次进行真机固件验收。

## 保留项与后续阶段

- 实体手机、手机HTTPS/PWA安装、模型准确率及长期业务试用未在本轮验收。
- Korvo核心PoC沿用原真实报告；0.5.0公共适配固件仍不能冒充已实刷，第二块真实板尚未适配。
- 无多人/多家庭账号与权限、微信Quick Mode、官方云、云同步或复杂跨截图订单对账。
- 没有离线库存写入、自动退款冲销或离线冲突合并。
- 手机BLE前台、复杂弱网、多天运行、电流和最终续航仍为后续专项，不继续抢占当前主功能顺序。

当前Local Mode清单中的软件主流程已收口。后续先按用户实际试用问题选择下一阶段大功能，不自行推进微信正式上线、定制PCB或消费级功耗承诺。样式/主题和原型板细节不再充当新的主功能开发阶段。
