## 构建中修正

1. 设置页组件的公共头文件已经迁入接口层，其 CMake 仍引用不存在的旧 `include` 目录，现已修正。
2. Korvo 演示入口与公共 `hs_queue_t` 契约保持一致，在适配器内部转换 FreeRTOS 队列类型。
3. Wi-Fi 名称显示显式使用 32 字节上限，解决体积优化时暴露的输出长度检查。
4. 首次默认调试构建生成 `0x400070` 字节镜像，超出 4 MiB 应用槽 112 字节。现默认使用 ESP-IDF 的 `CONFIG_COMPILER_OPTIMIZATION_SIZE=y`，保留调试符号及原有功能、分区布局。
