# T5 适配与验证记录

日期：2026-11-05。用户确认目前连接了主板和屏幕，其他配件待确认。固件按原厂 T5AI Board V1.02 和 3.5 英寸 320×480 触摸屏配置，具体屏幕型号仍需对照实物。

## 架构与代码

T5 和 Korvo 共同链接 `firmware/apps/freshmate/freshmate_app.c`。任务队列、计时、启动、日志和系统调用通过 `hs_runtime.h` 接入；网络、配置、传输和文件操作由 TuyaOpen 平台层实现，音频、屏幕与输入由 T5 板级工程实现。

共用录音队列保留原始采集 ID、损坏保护和失败重试；T5 录音回调只入队，磁盘写入由产品循环执行。PCM 队列满和输出失败都会返回错误。没有 SD 时仅继续联网与页面显示，不开放录音，不自动格式化或假装持久化成功。

原厂 SDK 的 FAT VFS 对缺失文件返回 FatFs 正数错误码，且目录遍历把错误与正常结束合并为 NULL。平台适配器分别归一化文件缺失和 I/O 错误，并在原厂 VFS 锁内检查真实 FatFs 目录返回值。首次构建缺少原生 OS 配置时自动编译独立引导工程，再从其真实编译数据库获得头文件路径；没有复制或伪造 SDK 的运行时类型。

目录与构建规则见 [固件入口](../../../firmware/README.md)，本地配置与烧录见 [T5 工程](../../../firmware/boards/tuya-t5-ai/README.md)。

- 根项目测试、lint、typecheck 结果及产物摘要见 [结构化记录](evidence/build-20261105.json)。公共能力策略另外执行主机 UBSan 检查；本机 ASan 运行时未正常退出，因此没有把它记为通过。

原厂 SDK 在 macOS 上默认使用系统 `ranlib`，会破坏 ARM 静态库索引。项目通过独立工具链补充配置选择 ARM `ranlib`，没有修改上游 SDK。FatFs 类型所包含的原厂 FreeRTOS 头会产生两条未使用 inline 声明警告，仅该适配文件不将这类警告升级成错误；其他应用源码继续使用 `-Werror`。

## 接板后的验收顺序

1. 核对主板版本与屏幕型号，检查原厂连接方式和供电，使用 TuyaOpen 工具烧录当前 QIO 镜像。
2. 验证启动、中文显示与触摸导航，再通过本地配置或串口连接 Wi-Fi 和 Core。
3. 检查设备登记板型、独立鉴权、心跳和六个业务页面；网络失败时不能把旧画面标成已刷新。
4. 确认 SD 后，验证录音→上传→库存处理→回复播报，并用同 ID 重试验证不会重复执行。
5. 对录音中断电、上传响应丢失、播放失败及 SD 异常分别验证恢复；不能继承 Korvo 的板级结论。

## 真机基础验证（0.6.1 → 0.6.4）

用户明确本轮只验证基础版本并保留文档；后续功能将大幅调整，Wi-Fi 留待后续，不继续展开联网业务验收。

- 0.6.1：完成实际烧录及镜像逐字节回读；应用正常进入主循环，LCD 初始化。真机日志给出原厂屏幕物理尺寸 320×480，发现旧横屏固定布局被裁切。
- 0.6.2：按实际分辨率布局，竖屏两行三列导航。用户确认显示正常、触摸切页正常，并要求改为横放使用。
- 0.6.3：T5 板级适配为原厂 ILI9488 LCD 登记独立显示名，在 SDK 初始化前设置 90° 旋转。原厂 LVGL 端口据此分配旋转缓冲区，使用逻辑 480×320 排版；触摸沿用真实 320×480 原始坐标，由 LVGL 的显示旋转映射。没有修改 SDK 源码。
- 配置串口改用 TAL UART 接收缓冲区及中断初始化；直接初始化 TKL UART 后轮询无法收到产品命令，不能把这种状态记为串口测试通过。
- 卡一直留在读卡器，T5 无卡启动时 SD 初始化失败是预期状态；应用继续运行页面，禁止录音。没有在这张原卡上做板端写入、格式化或录音测试。
- 卡完成 21 项业务文件备份与最终哈希复核后已安全弹出。T5 使用独立目录的代码回归通过，但板上 SD 挂载、音频录放、Core 联网闭环均留待后续。

0.6.3 的启动日志暴露显示名和触摸登记名不一致；0.6.4 已用同名登记修正，未修改 SDK。最终 0.6.4 已完成原厂烧录、镜像逐字节回读，启动确认逻辑尺寸 480×320、六列导航，没有触摸设备缺失错误。UART0（115200）产品命令及 UART1（460800）响应日志实测通过；发送无卡录音命令前后均返回 recording=0，确认无卡保护。用户最终确认：横屏显示和触摸均正常。结构化结果见 [最终验证记录](evidence/bring-up-0.6.4-20261105.json)。原始启动日志、烧录回读记录和固件保存在 `data/hardware/builds/tuya-t5-ai/` 的对应版本目录。
