## T5 使用规则

从 0.6.1 起，T5 使用 `/sdcard/homestash-t5`，ESP32 继续使用 `/sdcard/homestash`。原 `badge`、`homestash` 和出厂标记均保留。旧 T5 0.6.0 使用 ESP32 同名目录，不应在这张卡上启动。

主机回归运行真实录音恢复/提交/完成/缓存替换流程，并验证相邻 ESP32 目录的中断录音名称及每一个字节保持不变。主机测试不替代真机 SD 验证。

## 恢复与回用

正常回用 ESP32 只需安全弹出卡、断电换板，原目录无需搬迁。ESP32 启动后可能按原业务逻辑继续处理待提交录音/照片；这属于原功能，不代表调试损坏。

如确实需要恢复，先备份当时卡上的新数据，再根据 `manifest.json` 将备份 `files/` 下对应文件放回卡的相同相对路径，保持 UUID 和配套状态一致，并逐项核对 SHA-256。不要盲目覆盖后来产生的数据，不要格式化这张卡。
