# Korvo 页面与 Web 同步

2026-10-19。真实 LCD 固件新增六个触摸导航入口：今日、库存、临期、推荐、做饭、采购。Core 提供面向设备的只读页面投影，通用 Inventory Domain 不依赖 LCD。

## 行为

- 设备空闲时约每5秒读取当前页面，Web 的库存、菜谱、做饭步骤和购物清单更新可在下一次成功读取后显示；这不是 WebSocket 推送，不承诺固定延时。
- LCD 底部触摸按钮切换页面。SET 继续录音，MODE 负责拍照；录音和处理过程中忽略页面切换，避免覆盖操作结果。
- 语音/拍照完成后保留本次结果。点击导航返回页面后恢复自动同步；不自动播放 Web 的变更。
- 网络或 Core 不可达时显示未更新提示，重连后恢复读取。没有用缓存伪装实时库存。
- 今日摘要只展示未过期的临期食品；已过期项在临期页单独标明。库存、购物和推荐页是有限条目摘要，完整批次与编辑仍在 Web。长文本会受 LCD 可视区域限制。
- 做饭页读取真实 Cooking Session，包括完成与待确认状态；只有现有明确确认流程可以扣减库存。

## 边界

`GET /device/v1/screen?page=home|inventory|freshness|recipes|cooking|shopping`。使用既有设备 ID 和 Token，拒绝浏览器 Origin。返回 page、文字和文字摘要 revision；不暴露设置、API Key 或库存修改能力。内容长度限制为最多240个字符，适配现有设备接收缓冲。

本地端点和 Web 的 HTTP/数据库测试已覆盖：库存更新后投影改变、过期项隔离、Web 烹饪步骤变化、稳定 revision 和消息大小。**固件编译通过不等于触摸操作或实际 LCD 已验收**，真机状态以 `hardware-evidence/camera-20261019.json` 的页面验收字段为准。

串口可输入 `screen 0` 至 `screen 5` 切换页面，依次对应上述六页。监听工具支持 `--screen 5 --status`；这与实际触摸验收分别记录。

## 本次真机结果

已完整刷写并校验新版固件。串口切换采购页后，在真实 Web 添加“同步测试番茄”1个，设备日志与认证心跳均报告“待采购 · 1 项”；浏览器移除后设备报告“待采购 · 0 项”。临时清单项已撤销，库存与事件完整数据不变。首页也已取得真实数据。没有逐个进行物理触摸或屏幕画质检查，不能将串口切页当作触摸验收。

启动曾取得IP但连接Core超时；重启后约120秒恢复，具体网络根因尚未确定。当前实现提供未更新提示与自动读取重试，不表示已解决所有网络问题。
