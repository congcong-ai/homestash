# 手机局域网试用

手机与运行HomeStash的电脑连接同一可信家庭Wi-Fi；电脑保持开机，开发板无需联网。

```sh
pnpm dev:lan
```

打开启动日志中的 `http://电脑私有IPv4:实际端口/app`。默认网页起始端口3000；其他项目占用时向后寻找空闲端口。启动器只停止当前仓库目标端口上的旧监听服务，不清理其他项目。Core健康检查校验当前启动实例，避免误连旧服务。

首次未配置登录时，程序生成随机密码及签名密钥，保存在已被Git忽略的 `data/lan/`：

- `access.txt`：查看账号和密码，只保存在本机，不要分享或提交Git。
- `auth.env`：密码哈希和会话密钥，后续启动继续使用，不会每次重置。

目录权限0700、文件0600。已有 `INTERNAL_LOGIN_ENABLED=true` 时，必须提供有效的用户名、密码哈希和会话密钥；程序沿用原账号，不另写密码。无效配置拒绝启动。登录表单不预填密码；退出登录清除浏览器会话Cookie。

多网卡可设置 `HOMESTASH_LAN_ADDRESS` 为电脑当前已连接的家庭IPv4；只接受实际接口上的RFC1918地址，排除回环、公网、CGNAT及常见VPN接口。换Wi-Fi后重新运行并使用新地址，不承诺固定地址。需要允许操作系统防火墙接收入站连接；访客网络/AP隔离也可能阻止手机连接。

`pnpm dev` 仍为本机模式，不暴露Web到局域网。模式切换会重启本项目服务，浏览器使用新日志地址。`CORE_PORT`、`WEB_PORT`、`DEVICE_PORT` 可设置起始端口；Core管理接口始终只监听127.0.0.1，由网页同源代理转发。真实设备接口依然遵循独立配置；设备端口变化不会自动修改固件Core地址。

## 使用范围

当前入口用于可信家庭网络的开发试用，使用HTTP，不提供传输加密，不要做路由器端口映射或用于公网。正式部署沿用HTTPS服务器流程。单账号可管理当前本地家庭数据，没有多成员角色、独立家庭或云同步。

登录后可使用文字录入、库存批次/临期、待确认、采购清单、做饭与备份。数据存到原来的SQLite；登录信息不包含在家庭业务备份中。HTTP手机页面不注册Service Worker，不能把它当成已验收的安装、离线写入或浏览器麦克风方案。文件选图可走原有上传流程，直接调用相机的行为仍取决于手机浏览器，须另验。

建议首次手机试用依次检查：登录→查看库存和临期→添加一条购物项→标为已买→核对入库→查新批次→退出再登录。实际操作会保存到日常数据；不想影响原库存时可先在独立数据库中试用。

## 本轮验证

2026-10-22，使用临时数据库、Mock Provider、独立随机凭据启动真实私有IPv4入口。CLI经网页代理验证：匿名库存/备份401、未知Origin登录403、正确登录及HttpOnly/SameSite会话、库存读取、文字意图新增2个番茄、登录页无密码、退出清除Cookie、局域网直连Core被拒绝。

新增4组回归测试，验证地址选择、凭据持久化与权限、旧端口归属、外部进程保留及家庭账号跨Core重启继续登录；全量56项通过。lint、typecheck、Web生产构建和Core发布bundle检查通过。

初轮CUA内置浏览器和Chrome控制连接超时；后续经用户授权改用本地Playwright，已完成Chrome手机尺寸与主要交互验收，并修复HTTP请求ID和窄屏布局问题。按用户要求跳过手持真机，这些结果不能替代真实手机试用。详见[手机Web模拟验收](MOBILE_WEB_ACCEPTANCE.md)。未操作开发板、未调用外部模型。收尾将日常服务切到LAN模式，并只读核对登录后的库存与事件和切换前完全一致，没有新增或修改日常库存。
