# 小冰路演使用说明

## 电脑后台与现场配网

首次使用先按根目录 README 安装依赖、创建 `.env` 并配置设备凭据。日常在仓库根目录执行：

```sh
pnpm dev:lan
```

等待“后台已就绪”，打开终端打印的 `/app` 完整链接。家庭内部直接访问，不需要用户名、密码或成员权限；`/` 是官网首页，旧 `/login` 地址会跳转后台。Core 管理接口仅监听电脑回环地址，网页通过同源代理访问；开发板使用独立认证设备接口，默认端口为 3101。

所有产品与演示页面右上角都有“⚙ 设置”，默认打开网络页：重新扫描 → 选择 Wi-Fi → 输入密码 → 连接。密码不预填，返回会回到原页面。离线演示中打开设置会临时恢复网络供配网，返回后继续离线演示。

开发板与电脑接入同一 Wi-Fi 或手机热点，电脑保持唤醒、后台保持运行。真实产品显示“已连后台 / 未连上后台”，依据实际接口结果更新；Wi-Fi 连接成功不代表后台可达。

## 三种模式

| 模式         | 操作与数据                                                                                 | 验收边界                                                           |
| ------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| 真实产品     | 在模式选择页点击“返回主页”或按 SET 进入；SET 开始/结束录音，访问真实业务数据与后台语音服务 | 按键语音链路已有历史真机记录；本轮本地唤醒尚未通过声学验收         |
| 离线演示     | “进入演示馆”打开六个场景，PLAY/SET 推进固定台词和演示数据                                  | 14 条音频已有逐场景播放记录；不是实时 AI 对话                      |
| 联网语音演示 | Wi-Fi 连接后，使用本地 WakeNet/MultiNet 及有限词表，播放同一套固定答案                     | 不请求业务后台、不修改真实库存；完整声学链路尚未验收，保留按键操作 |

六场景：叫醒小冰、冰箱开门、你又来啦、草莓救援、今晚吃什么、电量告急。门与电量均为模拟事件。MODE 在演示操作卡中称为 PLAY。真实产品的“进入演示馆”可重新选择两种演示，需先结束当前任务。

已实现的语音流程：说“小冰小冰”后播放本地“我在，你说”，真实产品随后自动录音，连续静音约 1.2 秒或最长 10 秒时提交；手动录音最长约 59 秒。联网演示在唤醒后识别固定指令，会话在最后一次有效指令或播报结束后保持 60 秒，切换场景保留会话；期间可直接说提示词，超时后重新唤醒。说“退下”立即结束会话。角色在唤醒期间呈薄荷绿色，显示“已唤醒”；待机恢复粉色。唤醒词与指令同时检测，不再等旧指令窗口超时。为避免自声误触发，播报期间暂停监听，播完恢复；暂不支持打断正在播放的语音。固定指令包括：家里还有鸡蛋吗、怎么啦、小冰今晚吃什么、好呀开始做、下一步、马上给你充电、草莓怎么样、电量告急、打开冰箱、退下。

**上述自动语音流程已接入源码，但电脑扬声器播放唤醒词未命中，暂不能作为已验收的路演方式。路演优先使用 SET 真实录音，离线按键演示作为备用。** 模型初始化成功不代表实际唤醒成功，现场近距离、远场、噪声及回声表现仍需验证。

粉红色小冰使用 LVGL 原生图形，包含眨眼、聆听状态、说话口型等变化，字幕位于下方。配音采用 Momo 预生成语音，以 16 kHz IMA ADPCM 存在固件；短唤醒回应约 1.52 秒。播放不需要网络或运行时语音服务，扬声器听感和 LCD 像素布局仍需现场确认。

## 换热点时避免手动改 IP

Mac 可使用局域网名称作为 Core 地址。名称由以下命令查询，`pnpm dev:lan` 也会打印完整地址：

```sh
scutil --get LocalHostName
# 假设输出 HomeStash-Mac：Core 地址填 http://HomeStash-Mac.local:3101
```

换网后让 Mac 和开发板连同一网络，再重新执行 `pnpm dev:lan`。开发板获得新 IP 后会清除旧域名缓存、重新解析名称并重试后台连接。Mac 局域网名称需保持不变。

LAN 模式设备接口绑定全部网卡，端口固定；若被其他程序占用会明确报错，不静默换端口。Web 起始端口被其他项目占用时仍可自动避让，以终端为准。设备 ID 与令牌必须和后台一致；家庭用户无需账号不影响设备通信认证。

常用路演热点可在私有 `data/hardware/device.env` 配置 `WIFI_ROADSHOW_SSID` 和 `WIFI_ROADSHOW_PASSWORD`，保留默认、企业网络及屏幕保存的手动网络。新固件配置才会嵌入这些默认值；屏幕选网则在连接成功后保存到设备。不要公开配置文件或包含凭据的固件。

网络需允许 mDNS 和设备互访。若只屏蔽名称解析，可以在“设置 → Core”临时填写当前电脑 IP 和设备端口；若启用客户端隔离，需关闭隔离或换网络。真实云端 ASR、模型和 TTS 还需要互联网，固定演示音频不需要。

## 构建、刷机与验证

ESP-SR 2.6.0 使用 WakeNet“小冰小冰”和中文 MultiNet7。构建会生成 `build/srmodels/srmodels.bin`；模型分区位于 `0xc20000`，不移动既有 NVS、factory 和 OTA 应用地址。模型安装必须写入此镜像；仅应用 OTA 不更新模型。

完整构建和身份/备份校验后，按[固件 README](../README.md)使用 `scripts/hardware/flash.py`。`--dry-run` 只检查备份、地址与大小，不打开串口；带 OTA 初始化区时需提供 `--migration-backup`。完整刷写会初始化 OTA 选择并启动 factory，不能把它当成仅更新应用。

截至 2026-10-29 的证据：

- 路演固件已真实刷入并通过摘要校验；两个本地模型初始化成功，512 样本缓冲，新演示首页和设置面板正常加载，观察期间未见崩溃。
- 14 条离线配音有完整板上播放记录；14 条原音频与新增短回应通过固件 C 解码器和 FFmpeg 逐样本对照；开门事件防重复主机测试通过。
- 演示与真实页面的设置面板可打开/关闭，现场扫描到 16 个网络；此为板上业务路径验证，未代替手指点按和 LCD 像素验收。
- Mac 换网 IP 变化后，开发板保存 `.local` 地址并连续收到后台心跳成功；主动断开 Wi-Fi 后自动重连，后台心跳再次成功。新增常用热点配置已写入，不能将一个热点的实连结果推定为全部 SSID 或所有路由器均通过。

## 网络状态与返回主页修复（2026-10-30）

重复的恢复/暂停请求改为幂等操作，不再重启已经连接的 Wi-Fi；显式重连仍会重启。设置页配网后关闭面板保留连接，主页根据管理任务的同一份状态持续刷新。断开与获得 IP 事件合并时优先处理获得 IP，避免丢掉已连接事件。SD 挂载与媒体恢复移动到 LCD 启动前，返回真实页面不再执行这些初始化，并立即安排后台同步。已通过控制策略与连续会话主机测试；黑屏和实网表现仍需新版刷入后的真机回归，不能用编译成功替代。

真机复现补充：返回主页的黑屏实际包含崩溃重启，调用栈指向 ESP-SR 2.6.0 WakeNet9 的 `model_clean → dl_convq_queue_bzero`，首次推理前清理空队列会触发 Load access fault。移除 WakeNet 的 clean 调用，保持唤醒检测引擎连续运行；场景切换与退下只清理 MultiNet 指令缓存与会话状态。修复后须重新跑设置关闭、返回主页及网络心跳真机回归。

## Wi-Fi记忆与统一音量（2026-10-30）

网络连接对话框新增“记住密码，下次自动连接”勾选，默认勾选；最多保留8个界面保存的网络，兼容旧版单网络记录，连接成功后才保存。已保存网络在列表中显示标记，密码输入框留空可使用已保存密码，不显示明文。不勾选则本次使用，连接成功后移除该网络的界面保存记录；固件私有配置中预置的网络仍按固件配置参与自动连接。

“断开连接”会停止当前连接并暂停自动重连，之后可手动选择其他网络；“自动选择”可重新启用自动连接。

实体VOL+ / VOL−在真实与演示模式中统一调整音量，每次5%，范围10%–85%，屏幕短暂显示百分比。播报过程中也能调整，数值在音频播放循环中应用；停播/空闲后延迟保存到NVS，重启沿用。场景使用触屏选择，UART的demo-up/demo-down仍保留旧的场景选择诊断行为。

## 正式语音风格与勾选文字（2026-10-30）

Wi-Fi记忆勾选项显式绑定中文字体，修复默认字体导致汉字显示方框。正式语音默认采用与Demo一致的Momo音色；本机 `.env` 和默认配置已同步。设备库存播报按位置分组，同位置同名称同单位合并批次数量，最多先播报6样，其余在后台查看；完整库存结果和事件不改变。数量在名称之前，如“有哒！冷藏室里有10个番茄、2根香蕉”。保留过期警示及明确确认扣减等关键提示，不通过语言模型编造或改写库存事实。

设备播报缓存按音色/模型与回执文案区分，避免更换音色后沿用旧缓存。此前已保存的业务回执保持原文，新的录音会走新表达。新生成8.56秒示例样音供试听，音频生成及技术检查不代表自然听感已验收。

## 联网演示04/05/06接话修复（2026-10-30）

联网演示根据当前场景和步骤更新本地指令表，同时保留“退下”；场景切换时清理旧指令缓存，返回真实主页恢复完整词表。屏幕提示和指令路由共用一张表，避免提示词与实际等待的指令不一致。04草莓救援、06电量告急在唤醒后自动播放事件开场，接着分别等待“怎么啦”和“马上给你充电”，无需语音模拟原先的PLAY按钮。
